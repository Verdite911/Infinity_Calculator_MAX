Special syntax

  • Free letters become live variables automatically: mx+b means m*x+b and creates sliders for m and b.
  • a = 3 still creates an explicit slider/definition. Standard constants such as e, i, and pi remain constants.
  • Scroll/pinch or use ＋ / − to zoom. Curves are resampled after every pan/zoom, so graphs continue across the new viewport.
  • f(x) = ... defines and graphs a function.
  • integral(expr, a, b) computes a numerical definite integral; integrate(expr, x) is symbolic.
  • solve(expr, guess) numerically finds a root; solveExact(equation, x) uses the symbolic engine.
  • surface(expr) switches the graph to 3D. Remove the surface row to return to 2D.
  • Use the Math Library for many more operations and ready-made syntax.
  • Expression controls: ◉ hide/show graph, ⧉ duplicate, ▶ animate the first slider. Use ◎ to fit visible graphs.
