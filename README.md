# CalcMAX

An advanced graphing and mathematics calculator built with
HTML, CSS and JavaScript.

## Features
- Graphing
- Sliders
- Mathematical branches
- Calculus
- Geometry
- Statistics
- Matrices
- Complex numbers
- Unit conversion
- Calculation history
- Exact answers
- Interactive geometry

## How to run

Open index.html in a browser.

## Libraries
- Math.js
- Nerdamer
- Plotly.js
